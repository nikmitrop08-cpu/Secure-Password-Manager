# 🔐 Secure Password Manager

A desktop password manager built with Python and PySide6.

## Features

- 🔐 Master password protection
- 🔒 Fernet encrypted vault
- 🔑 Secure password generator
- 📊 Password strength checker and entropy calculator
- 📋 Clipboard copying
- ✏️ Edit and delete passwords
- 🖥️ Modern PySide6 graphical interface

## Security

- Master passwords are protected using bcrypt hashing
- Password vault data is encrypted using Fernet symmetric encryption
- User data is stored locally

## Installation (Linux)

Download:

SecurePasswordManager.AppImage

Make it executable:

chmod +x SecurePasswordManager.AppImage

Run:

./SecurePasswordManager.AppImage
